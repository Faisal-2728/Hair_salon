To add your salon photo to the public page:

1. Place your image file in this folder with the exact filename:
   salon-photo.jpg

2. Recommended size: 1600x400 (or wider). Optimize for web (JPEG/WEBP).

3. The public page (`frontend/index.html`) will show this image above the app root. If the file is missing, the SVG banner is used as a fallback.

If you want me to add the image file for you, upload the image into the workspace (or tell me the path of an existing file) and I'll copy it here and verify it displays.
